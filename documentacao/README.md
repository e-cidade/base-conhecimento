## Registro mínimo de uma afirmação

| Campo | Conteúdo exigido |
| --- | --- |
| Estado | verificado, proposta, hipótese ou pendente |
| Escopo | distribuição, módulo, ambiente |
| Origem | URL do repositório e mantenedor quando confirmado |
| Local | caminho, símbolo/trecho e commit imutável |
| Verificação | data e método: leitura, teste ou homologação |
| Limitações | acesso negado, amostra incompleta, conflito ou ausência de teste |
| Proveniência | autoria, licença e restrições de reutilização quando houver cópia |

**Verificado por leitura** não significa **testado em execução**. Não transforme catálogo em capacidade homologada, README em garantia de arquitetura ou silêncio documental em inexistência.

Use links por commit para comprovar afirmações e links da branch para descoberta atual. Quando fontes divergirem, registre ambas e investigue código/configuração da revisão. Não replique dados institucionais mutáveis ou privados.
