# Guia de contribuição

1. Abra uma issue descrevendo problema, escopo, fontes e versão/distribuição do e-Cidade quando pertinente.
2. Crie uma branch de trabalho e mantenha alterações focadas.
3. Identifique cada afirmação como **verificada**, **proposta** ou **pendente de validação** quando necessário.
4. Revise segurança, privacidade, autoria, licença e links.
5. Abra Pull Request com resumo, evidências, testes e riscos. Aguarde revisão de mantenedores; não faça merge automático.

## Licenciamento

A política de licenciamento ainda precisa de aprovação da comunidade. A ausência de licença explícita não autoriza reutilização irrestrita. Não copie conteúdo de terceiros sem conferir permissões.
