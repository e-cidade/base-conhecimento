# Manuais e instalação

O acervo comunitário está no [repositório manuais](https://github.com/e-cidade/manuais). Seus originais são organizados em 2014/, 2018/ e arquivos/. O README e workflow consultados estão fixados no [inventário](../documentacao/fontes/repositorios-e-cidade.md).

O catálogo é construído por scripts/build_site.py; o workflow instala ferramentas PDF e publica site/ no GitHub Pages. Os PDFs e demais originais não foram lidos nem copiados nesta entrega.

## Como escolher um manual

Identifique distribuição, versão, perfil e tarefa; confira a data e compare com código/configuração do ambiente. Manual histórico não valida telas, banco ou comandos atuais. Registre lacunas com caminho e evidência.

Para preparar o ERP, comece pelo [guia de ambiente](../desenvolvimento/README.md). As instruções Windows no README desta base instalam apenas a documentação.

Para contribuir um manual, informe autoria/licença, público, versão, pré-requisitos, passos e validação com dados sintéticos. Não incluir credenciais ou capturas com dados reais. Sem permissão de redistribuição confirmada, registre o link e a descrição própria.
